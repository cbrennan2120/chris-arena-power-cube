# Chris' Arena POWER Cube Dashboard

A premium, data-driven strategic primer and interactive dashboard for the Magic: The Gathering Arena Powered Cube format. This tool provides professional testing teams with high-velocity analysis, 17Lands win-rate data, and a P1P1 simulator.

## Features

- **P1P1 Simulator**: Practice drafting with random 15-card packs generated from the 540-card pool.
- **Card Database**: Search, filter, and sort the entire cube list including real-time win rate data.
- **Archetype Deep-Dives**: Technical breakdowns and key picks for major archetypes like Boros Aggro, UB Reanimator, and Breach Storm.
- **Visual Previews**: Hover over any card to see high-resolution art powered by the Scryfall API.
- **4th Edition Aesthetic**: A high-fantasy, nostalgic UI inspired by classic 1990s Magic the Gathering art.

## Technologies

- HTML5 / CSS3 (Vanilla)
- Javascript (ES6+)
- [Scryfall API](https://scryfall.com/docs/api) for card images.
- [17Lands](https://17lands.com) data for win rate analytics.

## How to Run

Simply open `index.html` in any modern web browser. No server or installation required.
